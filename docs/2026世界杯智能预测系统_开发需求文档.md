## 1. 项目概述

### 1.1 项目背景

2026 年 FIFA 世界杯由美国、加拿大和墨西哥联合举办，首次扩军至 48 支球队、12 个小组。赛事规模的大幅增长使得传统的人工分析和简单统计方法难以全面覆盖所有比赛预测需求。本项目旨在构建一套基于数学模型和数据驱动的智能预测系统，为每场小组赛和淘汰赛提供量化预测结果，包括比分概率矩阵、胜平负概率、大小球分析以及九维度综合实力对比。

### 1.2 项目目标

- 覆盖全部 48 支参赛球队的完整数据画像
- 对 72 场小组赛进行逐场量化预测
- 模拟 32 强淘汰赛完整路径并预测冠军
- 以交互式可视化仪表盘呈现所有分析结果
- 预测模型基于联网数据（FIFA 官方排名、FBref、Transfermarkt 等），而非大模型经验主义

### 1.3 核心设计原则

- **数据驱动优先**：所有预测结论必须基于可溯源的外部数据，赔率仅用于事后验证而非预测输入
- **高概率导向**：Agent 预测以高概率结论为输出标准，不做低置信度投机性预测
- **多维度交叉验证**：九维度评估体系覆盖球队近期状态、阵容实力、战术匹配等多个独立信号源
- **意外因素纳入**：模型需考虑伤病影响、气候适应、旅途疲劳等非技术因素

## 3. 数据模型

### 3.1 数据总览

系统核心数据为一份 JSON 文件，顶层结构如下：

```
{
  metadata          // 元数据（赛事信息、模型参数、维度定义）
  teams             // 48 支球队完整画像
  groups            // 12 个小组定义
  matches           // 72 场小组赛预测
  featured_matches  // 12 场焦点对决深度分析
  group_standings   // 12 组积分榜模拟结果
  knockout_bracket  // 淘汰赛完整路径预测
  championship_odds // 32 队夺冠概率
  tournament_summary // 赛事汇总统计
}
```

## 4. 预测模型设计

### 4.1 Dixon-Coles 泊松回归模型

本系统基于 Dixon-Coles 模型进行比赛比分预测，该模型是对标准泊松回归的改进，专门解决低比分场景下平局概率被低估的问题。

**核心公式：**

```
P(X=x, Y=y) = τ(x, y, λ, μ) × e^(-λ) × λ^x / x! × e^(-μ) × μ^y / y!
```

其中 τ 为低比分修正因子，在 x ≤ 1 且 y ≤ 1 时引入相关性参数 ρ。

**参数计算：**

```
λ_a = base_avg_goals × exp(strength_coeff × (strength_a - avg_strength)) × home_advantage_a
λ_b = base_avg_goals × exp(strength_coeff × (strength_b - avg_strength)) × home_advantage_b
```

**模型参数值：**

| 参数 | 值 | 说明 |
|------|----|------|
| base_avg_goals | 1.35 | 世界杯赛事基础场均进球 |
| avg_strength_anchor | 7.5 | 实力评分锚点 |
| strength_coeff | 0.30 | 实力差异对进球影响的指数系数 |
| home_advantage_concacaf | 1.12 | CONCACAF 球队（美/加/墨）主场加成 12% |
| correlation_rho | 0.05 × min(λ_a, λ_b) | 双变量相关性参数 |
| max_goals_truncation | 8 | 泊松分布截断上限 |

### 4.2 蒙特卡洛模拟

- 模拟次数：2,000 次完整赛事路径
- 模拟范围：小组赛全部 72 场 + 淘汰赛全部 32 场
- 随机种子：2026（保证结果可复现）
- 确定性判定：当强队胜率 ≥ 60% 时采用确定性结果，否则使用概率模拟
- 输出：各队晋级概率、夺冠概率、四强概率

### 4.3 九维度校准机制

在泊松模型的实力参数基础上，通过九维度评估体系进行动态校准：

1. 对每支球队计算 9 个维度的基础评分（基于 FIFA 排名、近期战绩、阵容数据等）
2. 战术匹配和历史交锋两个维度按具体对手动态计算
3. 按权重加权得出综合校准分，微调泊松参数 λ

### 4.4 外部条件修正

- **主场优势**：美国、加拿大、墨西哥三支 CONCACAF 球队获得 12% 的 λ 加成
- **旅途疲劳**：OFC（大洋洲）和 AFC（亚洲）球队因长途旅行获得轻微减分
- **气候适应**：北欧球队对北美夏季高温有适度减分
- **海拔因素**：墨西哥部分高海拔场馆对非高原训练球队有轻微影响

| CSS 框架 | Tailwind CSS (Play CDN) | 暗色主题 + glass-morphism 设计 |
| 图表库 | Chart.js 4.4.1 | 环形图、概率分布图 |

    ├── renderOverview()      → 渲染赛事总览

## 6. UI/UX 设计规范

### 6.1 设计主题

- **暗色主题**：深海蓝到暗紫渐变背景（`#070b14` → `#0f172a` → `#1e1b4b` → `#1a0a2e`）
- **背景层**：固定渐变 + 径向渐变 mesh 叠加层，营造深度感
- **Glass-morphism**：半透明卡片（`rgba(255,255,255,0.04)`）+ 毛玻璃模糊（`backdrop-filter: blur(20px)`）
- **顶部高光**：每张卡片顶部 1px 渐变高光线

### 6.2 色彩系统

| 用途 | 色值 | 变量名 |
|------|------|--------|
| 主强调（金） | #f59e0b | --accent-gold |
| 主胜/正面（蓝） | #3b82f6 | --accent-blue |
| 客胜/警示（红） | #ef4444 | --accent-red |
| 成功/晋级（绿） | #10b981 | --accent-green |
| 辅助（紫） | #8b5cf6 | --accent-purple |
| 主文字 | #f1f5f9 | --text-primary |
| 次文字 | #94a3b8 | --text-secondary |
| 弱文字 | #64748b | --text-muted |

### 6.3 交互规范

- **Tab 切换**：sticky 导航栏，选中态金色下划线 + 渐变背景
- **卡片 hover**：上浮 2px + 加深阴影 + 微蓝色光晕
- **比分矩阵**：hover 时放大 1.15 倍 + tooltip 显示精确概率
- **进度条**：0.8 秒 cubic-bezier 缓动动画
- **页面切换**：0.4 秒 fadeIn 动画
- **入场动画**：stagger 延迟（50ms 递增），fadeInUp 效果

### 6.4 响应式断点

| 断点 | 布局 |
|------|------|
| ≥ 1200px | 三列 / 四列网格 |
| 768px ~ 1199px | 两列网格 |
| < 768px | 单列，淘汰赛横向滚动 |

### 6.5 自定义滚动条

6px 宽度、圆角、半透明轨道、hover 加深。
